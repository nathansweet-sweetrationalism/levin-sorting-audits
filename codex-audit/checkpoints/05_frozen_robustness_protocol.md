# Checkpoint 05: frozen robustness protocol
This is a prospective, local protocol written after the historical audit and before these new runs. It is not an externally timestamped preregistration.
Run 30 fresh unique-key inputs of n=40, balanced B/S labels independently shuffled. Use seed root 20261101. Compare selection-pointer reset enabled/disabled and active-cell/all-cell scheduling in a 2x2 design. Use the same inputs across conditions. Primary descriptive outcome: final numerical sortedness and final/peak algotype aggregation. Negative control: the same labels are passive tags on cells all following Bubble; compare each run's peak to the matched control's peak, so the control includes the bias introduced by taking a maximum. No claim of original OS-thread replication. Save failures, capped runs and every run's outcomes. Interpret scheduler/state interactions as limitations on transfer of the surrogate's quantitative results. No post hoc adjustment of success definitions.
