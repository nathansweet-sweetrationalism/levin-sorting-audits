# Public-release note for this bundle

This folder is a rights-filtered copy of the Codex audit bundle. Every file in it is byte-identical to the private original; run `python3 ../verify_public_release.py` to check. Third-party full texts, page captures, the unlicensed original sorting repository, Joel Dietz's article text and one private correspondence-metadata record were removed. They are listed with their original SHA-256 in `PUBLIC_RELEASE_REMOVED_FILES.json`.

The bundle's own `README.md` and validator describe the private original. The validator therefore reports the removed files as missing; that is expected in this copy. Where the reports call the bundle private, or say that no public release was made, they describe its state before this release.
